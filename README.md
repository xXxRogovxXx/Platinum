# 🏆 Платиновый зал

Живой список пройденных на платину (PlayStation) и на 100% (ПК) игр — по годам, с 2012 года.

**Открыть страницу:** https://xXxRogovxXx.github.io/Platinum/

---

## Как добавить новую игру

Весь список хранится прямо в [`index.html`](index.html), в блоке между тегами:

```html
<script type="application/json" id="data">
{
  ...
}
</script>
```

Это обычный JSON: год → список названий игр.

1. Открой `index.html` на GitHub и нажми карандаш ✏️ (**Edit**).
2. Найди нужный год (например `"2026"`) и допиши игру в список — через запятую, в кавычках:
   - Платина на **PS5** → добавь в конце ` (PS5)`, например `"Hades II (PS5)"`.
   - Стопроцентовка на **ПК** → просто название, например `"Hollow Knight"`.
3. Внизу нажми **Commit changes**. Через минуту сайт обновится сам.

> Иконка каждой игре подбирается автоматически по названию. Если игра неизвестная — будет 🎮. Хочешь свою — можно добавить правило в блок `iconRules` внизу `index.html`.
