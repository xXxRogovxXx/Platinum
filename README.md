# 🏆 Платиновый зал

Живой список пройденных на платину (PlayStation) и на 100% (ПК) игр — по годам, с 2012 года.

**Открыть страницу:** https://xXxRogovxXx.github.io/Platinum/

---

## Откуда берётся список

Страница может работать в двух режимах:

1. **Из Google Документа (основной).** Список редактируется прямо в Google Docs, а страница подтягивает его на лету через маленький посредник — Google Apps Script (см. [`apps-script.gs`](apps-script.gs)). Ничего трогать в этом репозитории для пополнения списка **не нужно**.
2. **Встроенная копия (запасная).** Если Google Docs недоступен, страница показывает копию, зашитую в [`index.html`](index.html) (блок `<script id="data">`). Внизу страницы всегда видно, какой источник сейчас используется.

## Как добавить новую игру (для владельца)

Просто дописать её в **Google Документ**:

- Найти нужный год.
- Добавить название с новой строки.
- Платину на **PS5** пометить суффиксом ` (PS5)` — например `Astro Bot (PS5)`.
- Стопроцентовку на **ПК** — просто название.

Через несколько секунд после сохранения страница подхватит изменения сама. **Обложки** берутся из Steam по карте [`covers.json`](covers.json) (`точное название → Steam appid`) и грузятся с Steam CDN. Если игры нет в карте — показывается эмодзи-иконка по названию.

**Добавить/поправить обложку** вручную: открой [`covers.json`](covers.json) и допиши строку `"Точное название": "STEAM_APPID"` (appid — число из ссылки на игру в Steam Store). Commit — через минуту обложка появится.

## Настройка моста Google Docs → страница (делается один раз)

1. Открой Google Документ со списком → **Расширения → Apps Script**.
2. Вставь код из [`apps-script.gs`](apps-script.gs) (ID документа уже вписан). Никаких ключей не нужно.
3. **Deploy → New deployment → Web app**: *Execute as — Me*, *Who has access — Anyone* → **Deploy** → авторизуй → скопируй Web app URL (`…/exec`).
4. Открой [`index.html`](index.html), найди `var DATA_URL = '';` и вставь URL в кавычки. Commit.

> Обновляешь скрипт позже? **Deploy → Manage deployments → ✎ Edit → New version** — URL остаётся прежним.
